# Product Manager

Aplikacja Flask do zarządzania produktami.

## Technologie

- Python 3.12, Flask 3, Flask-SQLAlchemy
- SQLite
- Jinja2, CSS

## Zasady

1. Nazwy zmiennych, funkcji, plików i commitów po angielsku (`docs: ...`, `feat: ...`).
2. Przed każdym commitem uruchom `ruff check .` i popraw błędy.
3. Każda funkcja i klasa ma docstring.
4. Nie dodawaj nowych pakietów bez pytania.
5. Bazy danych z katalogu `instance/` nie commituj.
